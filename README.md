# 🎯 Sales Profit Power BI Dashboard

A business analytics dashboard built to help teams monitor sales performance, profit trends, customer behavior, and regional insights in one place. The dashboard is designed for managers and analysts to quickly understand business performance and make data-driven decisions.

✨ Technologies

- Power BI
- SQL
- Excel
- DAX
- Data Visualization

🚀 Features

- Tracks overall sales, profit, and revenue growth
- Visualizes regional and category-wise performance
- Interactive filters for dynamic business analysis
- KPI cards for quick performance monitoring
- User-friendly dashboard for reporting and presentations

📌 Project Workflow

This project starts with collecting and cleaning raw sales data from different sources. After preprocessing the data in SQL and Excel, the transformed dataset is imported into Power BI. DAX measures are then created for KPIs such as total revenue, profit margin, and growth percentage. Finally, interactive dashboards and visual reports are designed to help stakeholders easily analyze business trends.

🛠 How to Run

1. Download the `.pbix` dashboard file  
2. Open it using Power BI Desktop  
3. Refresh the dataset if required  
4. Use filters and visuals to explore insights
